# 实施计划: AI 潮玩城市 IP 介绍演示页

## 概述
创建一个独立的 HTML 交互式演示页面 `ai-city-ip-intro.html`，用于现场演讲展示《AI潮玩：用 TRAE 将城市 IP 游戏化的实践》。

## 技术约束
- 原生 HTML + CSS + JavaScript，不引入新框架
- 不使用外部 CDN 或外部图片
- 仅使用本地现有资源或 CSS/SVG 绘制
- 不修改游戏核心逻辑
- 不修改现有 PRD
- 通过 Vite dev server 访问：`http://localhost:5173/ai-city-ip-intro.html`
